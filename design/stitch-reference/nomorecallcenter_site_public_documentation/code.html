Comment ça fonctionne

Trois étapes simples pour restaurer la sérénité de votre smartphone, sans intermédiaires commerciaux ni télémétrie.

1

Installez l'application libre

Téléchargeable sans compte via F-Droid ou via APK signée. Fonctionne directement avec une base SQLite ultra-légère embarquée en local sur votre appareil.

storage Empreinte mémoire : < 8 Mo
2

Connectez votre instance

Rejoignez l'instance communautaire par défaut ou déployez votre propre backend Docker/Podman en 2 minutes pour synchroniser vos propres règles et listes.

hub Protocole chiffré REST / JSON
3

Activez le filtrage natif

Accordez le rôle officiel Android CallScreeningService : l'appareil rejette silencieusement les plages abusives avant même la première sonnerie.

do_not_disturb_on Rejet instantané en 0.8ms
Contrôle infrastructurel

Auto-hébergement souverain vs Instance de confiance

Choisissez la topologie qui convient à vos exigences d'administration et de confidentialité.

Option clé en main public

Instance communautaire modérée

Accès sans configuration technique. Synchronisation chiffrée périodique des plages ARCEP officielles et des signalements qualifiés et validés par l'équipe de modération bénévole.

  • check Mises à jour automatiques des règles ARCEP hebdomadaires
  • check Zéro inscription requise, authentification par token anonyme
  • check Hébergement associatif localisé en Union Européenne
Rejoindre via l'application F-Droid arrow_forward
Contrôle intégral terminal

Serveur autonome (Self-hosted)

Contrôle total via un conteneur unique sous licence AGPLv3. Stockage SQLite local, fédération peer-to-peer optionnelle et indépendance absolue de tout tiers (Google, AWS, cloud public).

docker-compose.yml Conteneur officiel 
services:
  nomorecallcenter:
    image: ghcr.io/nomorecallcenter/server:1.4
    restart: unless-stopped
    ports:
      - "8080:8080"
    volumes:
      - ./data:/var/lib/nomorecallcenter
    environment:
      - ARCEP_SYNC_ENABLED=true
      - TELEMETRY=disabled
  • check Gestion fine de vos listes blanches et expressions régulières (Regex)
  • check Support natif ARM64 pour Raspberry Pi & VPS économiques
